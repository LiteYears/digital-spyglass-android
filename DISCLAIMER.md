# Disclaimer & Limitation of Liability

**Last updated:** 2026-08-19

## Nature of the Software

Ghost ("the App") is a **search aggregator client**. It sends queries to
public `.onion` search engines via the Tor network, parses the returned HTML
for result links, and displays them in a list. The App **does not host,
produce, store, cache, or endorse any content**. It is a tool that retrieves
links from third-party search engines, similar to how a web browser retrieves
web pages.

## No Content Control

The App has **no content moderation capability**. Search results come from
public onion search engines and are displayed unfiltered. The App does not
and cannot:

- Filter, block, or remove illegal, harmful, or offensive content from results
- Verify the legality, accuracy, or safety of any linked content
- Control what third-party search engines index or return
- Prevent users from accessing any content via the returned links

By design, the App is content-agnostic. It retrieves links; it does not
evaluate them.

## No Tor Operation

The App is **not a Tor relay, exit node, or bridge**. It is a client
application that uses the Tor network via Orbot for transport. The developer:

- Does not operate any Tor infrastructure
- Does not control or monitor Tor network traffic
- Is not responsible for Tor network availability, speed, or security
- Is not affiliated with The Tor Project, Inc.
