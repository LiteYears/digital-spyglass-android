v4.1.0 — License change and security hardening

License: starting with this release, Ghost Search is distributed under
GPL-3.0-or-later (releases up to and including v4.0.1 remain under MIT).

New in this release:
- Signed engine registry: engine list verified at runtime against the APK
  signing key; search refuses to run if the registry fails verification.
  Registries now carry a sequence number with rollback protection — a
  tampered or replayed registry is rejected.
- Request fingerprint aligned with current Tor Browser on Android
  (UA, Accept-Encoding with gzip/deflate decoding, keep-alive)
- Task-hijacking hardening via empty taskAffinity
- Per-engine Tor circuit isolation documented and pinned by tests
- Bundled Ahmia blacklist snapshot so the opt-in abuse filter also works
  offline; live fetch still refreshes it
- Investigator workbench: entity graph, mirror-aware engine routing,
  hash-chained case files, PGP-anchored identities, tracking-strip
  detection, wallet enrichment and personas (all RAM-only, opt-in)
- Audit hardening: purge coverage extended to all session state, stricter
  registry-import validation (recursive forbidden-key rejection), case-
  sensitive entity dedup on extraction, graph and wallet layers, open
  circuit breaker skips mirrors of failed engines, panic wipe clears the
  webview, clearnet fetches require explicit opt-in
